How do I use what people type?
  1. Add controls, like an Edit box and a Button.
  2. Select the Button and press ✨ Make it do something.
  3. Inside the block it makes, add actions. On any text box, press {} and pick “Text typed in ed1”.

Example: a message of Hello {ed1}! shows what was typed. Try the “Form” template.

    Getting what the user typed in your window
    • Every control has a name (like ed1). Select a control to see or change it.
    • Put actions in a “When control event happens” block. The UI Designer’s ✨ Make it do something button creates one for you.
    • On blocks with a {} button, click it to insert the text typed in a box, the picked dropdown item, a checkbox, or a variable. In text it shows as {ed1}.
    Good to know
    • Yellow outline on a block means the Problems panel found something.
    • Use Hotkeys can interrupt themselves (on by default) so pressing a toggle hotkey a second time can switch a loop off.
    • Drop an .ahk or .ahkb file on the window to open it in a new tab.
    • The Code view is the best place for big hand-written scripts. Switch back to Blocks any time.
